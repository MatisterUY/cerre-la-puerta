# Contributing

Thanks for helping improve **¿Cerré la puerta?**.

## Issues

Before opening an issue, check for existing reports. Include a clear description, steps to reproduce, browser/device details, and expected/actual behavior. Please avoid sharing personal address information or screenshots that reveal private confirmation history.

## Pull requests

1. Fork the repository and create a descriptive branch.
2. Keep changes small and document user-facing features in the README.
3. Run `npm test` and check accessibility (keyboard, touch, labels, focus, contrast).
4. Open a PR describing the motivation, implementation, and testing.

## Design principles

- Privacy first: no tracking, no backend requirement, no hidden data transmission.
- Never imply the app **knows** whether a physical door is actually closed.
- Keep the app fast, mobile-friendly, and usable offline.
- No new dependency without a clear justification.

Code of conduct: be respectful, assume good faith, and keep discussions focused on improving the project.
